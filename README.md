# Mithun Kumar — Personal Portfolio

A responsive, single-page portfolio website for a graphic designer.

## Features
- Responsive layout for desktop, tablet and mobile
- Work gallery, about, services and contact sections
- Mobile navigation and subtle hover motion
- No build tools or framework required

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Open the repository **Settings → Pages**: https://github.com/MithunKumar2003/mithun-portfolio/settings/pages
2. Under **Build and deployment**, set **Source** to **GitHub Actions** and save.
3. Open **Actions → Deploy portfolio to GitHub Pages** and choose **Run workflow** on the `main` branch.
4. After the workflow succeeds, your website will be available at: https://mithunkumar2003.github.io/mithun-portfolio/

## Customize before sharing
- Replace the concept-study gallery cards in `index.html` with real project images and descriptions.
- Update the placeholder email and social links in the contact section.
- Update the location, skills and biography to reflect your preferred details.

The current gallery artwork is CSS-based concept artwork, not a claim that these are completed client projects.

## Add your hero portrait
Upload the supplied PNG as `assets/mithun-hero.png` (create the `assets` folder first). The hero section is already configured to display that exact path.
